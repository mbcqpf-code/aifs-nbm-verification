AIFS vs. NBM Medium-Range Temperature Verification

Evaluating ECMWF AIFS against NBM 06z QMD relative to NOAA URMA Analysis

⚠️ Methodological Notes & Proxies:
  • Not a True AIFS Max/Min: Because the AIFS Open Data ensemble provides 6-hourly steps, 12z is used as the proxy for Min T, and the higher of 18z and 00z is used as the proxy for Max T.
  • Ensemble Mean vs. Median: AIFS represents the native 0.25° Ensemble Mean. NBM represents the 06z cycle QMD 50th percentile (Median), which is delivered operationally as the 13z NBM package.
  • Truth Baseline: Verifications are calculated against the NOAA 2.5km URMA daily analyses regridded to an identical 0.25° CONUS mesh.
